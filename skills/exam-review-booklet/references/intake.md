# 标题和日期：每次新卷的互动指引

目的：孩子拿到纸张时，能知道这页来自哪次卷子。标题与考试/作业日期属于用户确认的信息，不是从照片文件名推导出的事实。

## 候选值怎么来

先看原图卷首。分别记录卷面标题、卷面日期、文件夹标签；只将拍摄时间或 EXIF 当拍摄信息。年份没有写出时，不擅自补全年份。可以把当前上下文支持的年份作为“待确认候选”，不能标成卷面已明确写出的年份。

例：文件夹名“10月月考”，卷面写“9月综合作业”，日期栏未见具体日。提示应是：

> 文件夹写“10月月考”，卷面标题是“八年级数学9月综合作业”。打印标题与日期由你确认；不会把拍摄日当考试日。

不要把示例月份或本技能创建时间用于下一份试卷。

## 一份试卷：两个简短问题

有异步用户提问工具时，按当前候选值发起一次问题组。以下是调用结构示例，运行时用实际识别值替换：

```json
{
  "questions": [
    {
      "title": "这次讲评册的标题用哪个？识别到卷面标题为‘八年级数学第八周练习’。可以选候选项，也可以直接输入完整标题。",
      "options": ["八年级数学第八周练习", "八年级数学练习"]
    },
    {
      "title": "卷面写‘10月21日’，没有年份。打印日期用哪一个？也可以直接输入你确认的日期。",
      "options": ["10月21日（年份未提供）", "日期未提供"]
    }
  ]
}
```

工具的自填入口用于直接输入标题或日期；不要将“自填”本身作为最终值。候选项只填真实有依据的值。未识别到标题或日期时，该问题省略 options，直接请求输入，并明确允许日期填“日期未提供”。

异步工具不会阻塞等待答案：提问后可以继续做独立识题和分析；收到答复再形成确认记录。缺一个字段时只补问缺的字段，不重问整组。未答复不能将预选候选视为用户已提交。

没有提问工具时，用一条消息显示两行：

> 请确认或直接修改：
> - 标题：……
> - 考试/作业日期：……（可填“日期未提供”）

之后等待真实答复。不要声称技能自己能跨客户端打开一个固定的原生窗口。

## 多份试卷

每份有自己的 metadata，不将同一个日期无声套用到所有卷。两份时，可各用一个问题卡，卡内列出标题、日期；用户可以回复“确认”或“标题：……；日期：……”。超过三份按小批次确认，保留已确认的值。

用户说“这两份合成一本”时，先分别确认两份身份；可分别渲染后按原页合并 PDF，保留每页原本的标题与日期。不要生成一个会覆盖所有试卷日期的总页眉。

## 存储确认记录

只有得到答复后才写：

```json
{
  "exam": {
    "title": "八年级数学第八周练习",
    "exam_date": "10月21日（年份未提供）",
    "generated_at": "2026-10-25T15:30:00+08:00",
    "confirmation": {"title": true, "exam_date": true}
  }
}
```

`generated_at` 取实际生成时的用户时区时间；例子只是示范格式。它从不填入 `exam_date`。用户明确选择日期未知，也算已确认，打印“日期未提供”。

每页检查：标题、考试/作业日期、题号都在；生成时间位于页脚且有不同标签。更新已确认册子的讲解时无需再确认，除非用户更换试卷或修改元数据。
