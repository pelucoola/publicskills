# 常驻指令配置

用户可在同一条安装请求中指定私有 Git 地址、启用自动管理的范围，以及是否自动同步。安装好 Skill 文件后，读取其中的 `SKILL.md`，绑定记忆仓库，再把下面的区块写入所选范围。已绑定的仓库可以复用。

## 选择指令文件

- **Codex 全局**使用 `$CODEX_HOME/AGENTS.md`，未设置 `CODEX_HOME` 时使用 `~/.codex/AGENTS.md`。同级有正在生效的 `AGENTS.override.md` 时，更新该文件。
- **Codex 项目**使用用户指定项目的 `AGENTS.md`，或该目录正在生效的 `AGENTS.override.md`。用户只说开启自动管理时，默认用已确定的项目范围。没有确定项目时，向用户确认作用范围。
- **其它 Agent**按宿主支持的项目或全局常驻指令入口放置。如果客户端没有可编辑的持久指令入口，给出区块供用户加入设置。

## 写入与维护

保留指令文件的其它内容。新启用时追加下方区块，重复配置时更新标记之间的内容，关闭自动管理时只移除这个区块。标记缺失一半或存在多组时，先核实要修改的范围。写完复核区块和其余内容，并告知写入的文件路径。更改在宿主重新载入指令后生效。

```markdown
<!-- personal-memory:start -->
## 个人长期记忆

在已有项目、需要长期偏好或需要延续先前决定的任务开始时，调用 personal-memory，拉取并读取相关记录。任务结束时，按 Skill 的规则判断是否有经确认、会被后续任务复用的信息。只在内容有实际变化时更新记忆。

自动管理范围为已绑定记忆仓库的读取、更新与本地提交。远程推送由当次同步请求授权。
<!-- personal-memory:end -->
```

用户明确开启自动同步时，把最后一段改成以下内容：

> 自动管理范围为已绑定记忆仓库的读取、更新、本地提交，以及将这些经核对的记忆更新推送到已绑定的私有分支。

常驻指令内写规则。仓库地址、分支和认证沿用本机绑定。使用自定义记忆目录时，在客户端启动环境里设置 `PERSONAL_MEMORY_DIR`，使后续任务能找到同一目录。新电脑或新的 Agent 用同一记忆仓库重新绑定，并在该宿主启用相同规则。Codex 的指令文件发现规则见 [AGENTS.md 文档](https://learn.chatgpt.com/docs/agent-configuration/agents-md)。
