# 记忆归属与目录

先确定信息适用的范围，再查看对应目录。根目录 `README.md` 只索引个人资料和项目入口。

```text
README.md
personal/
  profile.md           用户本人的长期资料
  preferences.md       用户明确指定为长期沿用的个人偏好
projects/
  <project-id>/
    README.md          项目索引与用途
    notes.md           经用户要求保存的项目决定、规范或进展
```

- **个人资料与偏好**。用户本人的已确认事实、跨任务的长期偏好，或者用户明确要求保存为个人记忆的内容。个人自动管理以当前 Agent 的已选范围为准。一个项目内的「以后都这样」仍按该项目范围理解。
- **项目记忆**。用户明确要求查阅、记录、整理或同步指定项目的记忆时，只操作该项目的目录。使用小写英文、数字和连字符组成的稳定 `project-id`；已有目录时沿用。若同名项目无法区分，先确认目标。用户指定写到项目自身仓库时，沿用该仓库的文档位置与授权。
- **当前任务资料**。交付要求、草稿、过程记录和一次性约束保留在任务上下文或任务文件。用户明确要求留档时再按适用范围归档。

每次更新修订已有条目，保留必要的来源和日期，按实际需要增加文件。自动个人写入以 `personal/` 及根索引里的个人链接为范围，旧个人文件迁移按下一节处理。项目索引和内容跟随明确的项目记忆请求更新。确认待推送提交符合该次授权后再推送。

## 旧记录兼容

旧版根目录中的 `profile.md` 等条目按实际内容判断。自动查阅可读取归属明确的旧个人条目；旧项目条目按项目记忆的手动规则访问。已确认只含个人资料的旧文件，在实际更新该资料时可移到 `personal/` 并更新索引。项目旧记录在用户明确请求整理或更新它时归入对应项目目录。旧文件混有多个范围时，只处理本次明确授权的条目。Git 保留历史版本。
